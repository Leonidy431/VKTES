## Blind Spots Audit — BS-1..BS-99

Полный систематический аудит расхождений кода/чертежей/документов, по
запросу оператора («найди 99 слепых зон по коду и чертежам»). Полная
таблица с деталями: **`docs/blind_spots_audit.md`**. 6 находок исправлены
кодом сразу же (см. «Done» ниже); 93 требуют аппаратного, архитектурного
или процессного решения и не могут быть закрыты одной правкой кода —
ниже перечислены только 7 «золотых» находок по категориям (самые
системные в каждой) плюс BS-99, остальные 92 — см. полную таблицу в
`docs/blind_spots_audit.md`.

| # | Категория | Находка (сокращённо) |
|---|---|---|
| BS-14 | Электробезопасность | Нет протокола периодической поверки/калибровки GFCI/IMD/AFCI. |
| BS-28 | Аэродинамика/климат | Whiteout/brownout не имеет fallback-поведения — сенсоры не проверяют качество данных перед использованием. |
| BS-42 | Механика/крепёж | Нет ни одного теста, симулирующего потерю компонента (отвал, лыжа) в полёте. |
| BS-56 | Кабель/станция | Единственная сигнальная пара MAVLink без резервирования — при повреждении дрон теряет и телеметрию, и управление одновременно. |
| BS-70 | Навигация/восприятие | Нет сенсорной избыточности — LiDAR/камера/тепловизор работают независимо, результаты не сверяются. |
| BS-84 | Архитектура ПО | `pyproject.toml` без секции `[project]` — нет гарантии воспроизводимости окружения. |
| BS-98 | Тестирование/документация | Нет автоматической sanity-проверки согласованности `config.SNOW_RESISTANCE_*`/`TILT_THRUST_TABLE` с числами из `engineering_review.md`. |
| BS-99 | Системная | Вердикт эксперта «Безопасность 3/10» никогда не был формально закрыт — нет ADR, принимающего/отклоняющего 4 critical issues рецензии. **Требует решения оператора**, не может быть закрыт агентом односторонне. |
