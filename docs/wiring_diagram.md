## Разъёмы и защита

| Точка | Разъём | Защита |
|---|---|---|
| Кабель → Дрон | Anderson PP75 (600V) | Предохранитель 50А |
| Vicor → Шина 48V | XT90-S (антиискровой) | TVS-диод 60В |
| ESC → Мотор | 4мм bullet | — |
| Cube Orange+ питание | 5V BEC (Mauch) | Двойное резервирование |
| Отвал → Лыжи | Магнитные замки | Срезные болты (40 кг) |
