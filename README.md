## Концепция

**Проблема:** Очистка крыш от снега — тяжёлый и опасный ручной труд. Существующие дроны не способны работать в режиме «тягача» из-за ограниченной ёмкости аккумуляторов.

**Решение:** Привязной дрон на лыжах с клиновидным отвалом, питающийся от наземной суперконденсаторной станции через силовой кабель (tether). Станция заряжается от обычной бытовой розетки 220В/16А и выдаёт импульсную мощность до 15 кВт.

**Цикл работы:** Зарядка (2 мин) → Взлёт и посадка на крышу → Толкание снега к краю (30–45 сек) → Возврат на зарядку.

## Раздел 1. Конструкция отвала (The Blade)

**Задача:** Создать форму, которая не опрокинет дрон при ударе о препятствие и будет сбрасывать снег, а не накапливать его.

### 1.1. Геометрия и форма

| Параметр | Значение |
|---|---|
| Тип | Клиновидный отвал (V-plow) |
| Угол атаки клина | 90° (по 45° в каждую сторону от оси движения) |
| Профиль ножа | Эллиптический (вогнутый внутрь) — снег закручивается и выбрасывается в стороны |
| Ширина захвата | 1200 мм (шире базы лыж на 10 см с каждой стороны) |
| Высота отвала | 300 мм |

```
        ┌── 1200 мм ──┐
        │              │
   ═══╗      V-plow      ╔═══
      ╚══════╗  ╔══════╝
             ║  ║  ← Ось движения
        ─────╨──╨─────
        │   Лыжня    │
        └── 1000 мм ──┘
```

**Обоснование угла 90°:** Оптимальный компромисс между «разрезанием» сугроба и минимизацией лобового сопротивления. Более острый угол потребует большей горизонтальной тяги; более тупой — создаст «стену» перед дроном.

### 1.2. Материалы и вес

| Компонент | Материал | Обоснование |
|---|---|---|
| Корпус отвала | Поликарбонат (монолитный) 4–5 мм или UHMWPE | Снег не липнет, не трескается на морозе (карбон хрупок на удар) |
| Кромка (нож) | Сменная полоса — резина ТМКЩ (твёрдая) или полиуретан | Жёсткий металл запрещён: зацеп за гвоздь/шуруп на крыше вызовет аварию |
| **Общий вес узла** | **≤ 3.5 кг** | — |

### 1.3. Система крепления и защиты (Anti-Crash)

- **Точки крепления:** Отвал крепится **строго к лыжам (шасси)**, а не к раме дрона. Вектор тяги проходит через центр отвала.
- **Механизм «Плавающий нож»:** Вертикальный ход 5–10 см для огибания неровностей крыши без подъёма самого дрона.
- **Защита от опрокидывания:** Магнитные размыкатели или срезные болты (пластиковые). Порог срабатывания — **40 кг**. При ударе в трубу/парапет отвал отстёгивается, дрон перелетает препятствие.

```
 Нормальный режим:          При ударе (>40 кг):
 ┌──────────┐               ┌──────────┐
 │  ДРОН    │               │  ДРОН ↗  │  (перелёт)
 ├──────────┤               ├──────────┤
 │  ЛЫЖИ   │───[магнит]───│  ОТВАЛ   │  (отстёгнут)
 └──────────┘               └──────────┘
```

## Раздел 2. Энергетическая установка (Supercapacitor Ground Station)

**Задача:** Обеспечить импульсную мощность **15 кВт** при входном ограничении **3.5 кВт** (бытовая розетка).

### 2.1. Расчёт банка суперконденсаторов

| Параметр | Значение |
|---|---|
| Требуемый запас энергии | 600 кДж (40–60 сек на полной тяге) |
| Базовый модуль | Maxwell BMOD0165 P048 (48V, 165F) |
| Энергия одного модуля | ~190 кДж (53 Вт·ч) |
| Вес модуля | 13.5 кг |
| Конфигурация | **3 модуля параллельно** |
| Итоговая ёмкость | **495 Ф при 48В** |
| Итоговая энергия | **~570 кДж** |
| Общий вес батареи | **~41 кг** (стационарная) |

Формула запасённой энергии:

```
E = ½ × C × V² = ½ × 495 × 48² = 570 240 Дж ≈ 570 кДж
```

### 2.2. Схема преобразования (Circuit Topology)

Напряжение на конденсаторах падает с 48В до 24В по мере разряда. Необходим DC/DC преобразователь с широким входным диапазоном.

```
 ┌─────────────┐     ┌──────────────┐     ┌──────────────────┐     ┌─────────┐
 │  220V AC    │────→│  AC/DC PSU   │────→│  Банк ионисторов │────→│  HV     │
 │  (Розетка)  │     │  48V / 3 кВт │     │  495F / 48V      │     │  Boost  │
 │  16A max    │     │  CC/CV заряд │     │  570 кДж         │     │  DC/DC  │
 └─────────────┘     └──────────────┘     └──────────────────┘     └────┬────┘
                                                                        │
                                                                   400V DC
                                                                        │
                                                                   ┌────┴────┐
                                                                   │  Кабель │
                                                                   │  50 м   │
                                                                   │  2×6мм² │
                                                                   └────┬────┘
                                                                        │
                                                                   ┌────┴────┐
                                                                   │  ДРОН   │
                                                                   └─────────┘
```

**Ступени преобразования:**

1. **Вход (зарядка):** Блок питания AC/DC 220V → 48V (3000 Вт). Ограничение тока заряда (CC/CV), чтобы не выбить автомат.
2. **Банк ионисторов:** Шина 48В.
3. **HV Boost Converter (сердце системы):**
   - Вход: 24–50V DC (wide input)
   - Выход: **400V DC** (стабилизированное)
   - Мощность: 15–20 кВт пик
   - Рекомендация: серверные БП Eltek/Huawei в режиме Boost, либо IGBT-сборка с управлением на STM32

### 2.3. Кабель (Tether)

| Параметр | Значение |
|---|---|
| Напряжение | 400V DC |
| Ток | 15000 Вт / 400 В = **37.5 А** |
| Сечение | 2 × 6 мм² (AWG 10) |
| Тип | КГтп-ХЛ (морозостойкий) или ROV-кабель (кевларовая жила) |
| Длина | **50 метров** |
| Потери напряжения | ~15–20 В (приемлемо) |

## Раздел 3. Лётная платформа (Aerosleigh Drone)

**Задача:** Обеспечить выживаемость аппарата при работе в режиме «тягач».

### 3.1. Компоновка (Airframe)

| Параметр | Значение |
|---|---|
| Схема | Октокоптер X8 (соосные винты) или гексакоптер |
| Центровка | Задняя — передняя часть (камера) приподнята на лыжах |
| Горизонтальная тяга | За счёт наклона вектора тяги, а не всего корпуса |
| Альтернатива | 2 маршевых импеллера (EDF) сзади |

**Принцип работы на земле:** Дрон не наклоняется целиком (как в полёте). Вместо этого используется горизонтальная составляющая тяги от задней центровки. Это сохраняет устойчивость на лыжах.

### 3.2. Винто-моторная группа (ВМГ)

| Компонент | Спецификация |
|---|---|
| Моторы | T-Motor U10 II или U12 (KV 100), IP55 |
| Пропеллеры | 28–30 дюймов |
| Бортовой конвертер | Vicor BCM (Bus Converter Module) |
| Вход конвертера | 400V DC (с кабеля) |
| Выход на ESC | 12–14S (50–60В) |
| КПД конвертера | **98%** |
| Вес конвертера | ~200 г |

### 3.3. Шасси (Лыжи)

| Параметр | Значение |
|---|---|
| Длина лыж | 1.5 м |
| Подошва | Тефлон (PTFE) |
| Расстояние между лыжами | 1.0 м |
| Тип | Широкие «снегоходные» |

## Раздел 4. Регламент работы (Operations)

### Фаза 1: Зарядка («Накопление гнева»)

```
[██████████░░░░░░░░░░] 50%  ← Зарядка ионисторов
```

- Дрон стоит на земле / сидит на крыше (винты выключены)
- Наземная станция тянет **16А** из розетки
- Время: **120–150 секунд**
- Индикация: зелёный свет на станции (**Ready to Burst**)

### Фаза 2: Удар («Высвобождение»)

```
[████████████████████] 100%  ← BURST MODE
```

1. Пилот поднимает дрон (вертикальный взлёт, потребление ~5 кВт)
2. Посадка на точку начала очистки
3. Включение режима **"Bulldozer"**: винты на 90–100% мощности → горизонтальная тяга
4. Дрон толкает снеговой пласт к краю крыши
5. Время работы: **30–45 секунд**

### Фаза 3: Отход

```
[████░░░░░░░░░░░░░░░░] 20%  ← LOW POWER — ожидание
```

- Напряжение на конденсаторах падает до **24В** → сигнал пилоту
- Дрон взлетает вертикально или остаётся на месте
- Переход в режим ожидания (**Low Power**)
- Станция начинает новый цикл зарядки

### Диаграмма рабочего цикла

```
Мощность
  15кВт ┤         ┌─────┐
        │         │BURST│
        │         │     │
   5кВт ┤    ┌───┐│     │┌───┐
        │    │FLY││     ││FLY│
   3кВт ├────┤   ├┤     ├┤   ├────── (зарядка)
        │CHRG│   ││     ││   │CHRG
      0 └────┴───┴┴─────┴┴───┴──────→ Время
        0   120s 150s  180s 195s 315s
```

## Раздел 5. Модуль BlueOS — Полуавтоматическое управление

Модуль **BlueOS** — программный компонент, работающий поверх ArduPilot (полётный контроллер Cube Orange+). Он обеспечивает полуавтоматический режим работы дрона: распознавание поверхности крыши, планирование дорожек очистки и управление циклами заряд/разряд наземной станции.

### 5.1. Архитектура модуля

```
┌─────────────────────────────────────────────────────┐
│                   BlueOS (Оператор)                 │
│                                                     │
│  ┌─────────────┐  ┌──────────────┐  ┌────────────┐ │
│  │  Perception  │  │   Planner    │  │  Power     │ │
│  │  Module      │→│   Module     │→│  Manager   │ │
│  │  (Зрение)   │  │  (Маршруты) │  │  (Энергия) │ │
│  └──────┬──────┘  └──────┬───────┘  └─────┬──────┘ │
│         │                │                │         │
│  ┌──────┴────────────────┴────────────────┴──────┐  │
│  │           MAVLink / DroneKit Interface         │  │
│  └───────────────────────┬───────────────────────┘  │
│                          │                          │
└──────────────────────────┼──────────────────────────┘
                           │
                    ┌──────┴──────┐
                    │  ArduPilot  │
                    │ Cube Orange+│
                    └─────────────┘
```

### 5.2. Модуль восприятия (Perception Module)

Использует камеру (вниз) и LiDAR для:
- **Определения границ крыши** (edge detection)
- **Обнаружения препятствий** (трубы, антенны, парапеты)
- **Оценки толщины снежного покрова** (по разнице высот LiDAR)
- **Классификации поверхности** (снег / лёд / чистая кровля)

### 5.3. Модуль планирования (Planner Module)

Строит оптимальные дорожки (lanes) для очистки:
- **Boustrophedon-паттерн** (зигзаг) — с учётом ширины отвала 1.2 м
- **Направление к ближайшему краю** — чтобы минимизировать расстояние сброса
- **Зоны исключения** — вокруг труб и антенн (буфер 0.5 м)

### 5.4. Менеджер энергии (Power Manager)

Управляет циклом заряд/разряд:
- Мониторинг напряжения банка ионисторов в реальном времени
- Автоматический переход между фазами (Charge → Burst → Low Power)
- Аварийное прерывание при просадке ниже **24В**

### 5.5. Режимы работы

| Режим | Описание |
|---|---|
| `IDLE` | Ожидание. Дрон на земле, зарядка |
| `SURVEY` | Облёт крыши, построение карты |
| `TRANSIT` | Перелёт к точке начала дорожки |
| `BULLDOZER` | Активная уборка — толкание снега |
| `RETREAT` | Возврат на зарядку |
| `EMERGENCY` | Аварийный режим — отстыковка отвала, зависание |

### 5.6. Протокол связи с наземной станцией

```
Дрон (BlueOS)  ←──── MAVLink Tether ────→  Наземная станция (GCS)
                                              │
     Команды:                                 │  Телеметрия:
     - START_CHARGE                           │  - voltage: 48.2V
     - STOP_CHARGE                            │  - current: 32.1A
     - BURST_READY?                           │  - energy: 540kJ
     - EMERGENCY_STOP                         │  - temp: 22°C
                                              │  - state: CHARGING
```
